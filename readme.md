# Amaze Amaze Amaze

A simple asteroid-dodging game built with pygame.

## Setup

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
2. Run the game:
   ```
   python main.py
   ```
3. Click anywhere on the start screen to begin.

## Controls

- Arrow keys to move
- Space to shoot
